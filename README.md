# 🏡 Airbnb Clone – Project Overview
📌 Project Description
This project is a backend clone of Airbnb, designed to simulate the core functionalities of a property rental platform. It includes user authentication, property listings, bookings, and reviews. The goal is to practice building scalable RESTful APIs and deepen understanding of real-world backend system design.
